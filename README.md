# Argama EC Core

ArgamaのAmazon・楽天市場・eBayなどのEC業務を管理するための開発基盤です。

## ディレクトリ構成

- `amazon/`: Amazon向けの業務管理機能を配置する場所
- `rakuten/`: 楽天市場向けの業務管理機能を配置する場所
- `common/`: 各ECモールで共通利用する処理や資料を配置する場所

eBay向けのディレクトリは、実装に着手する際に追加します。

## 現在の状態

初期構成のみ作成済みです。アプリケーション、外部サービス接続、API設定、追加パッケージはまだありません。実行・テスト手順は実装時に整備します。

作業方針は `AGENTS.md`、進捗は `STATUS.md` を参照してください。

既存のAmazon売上再建プロジェクトは独立して扱い、このリポジトリの初期設定では変更・移動・取り込みを行いません。
